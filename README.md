# LYTOS — Laboratory of Yield, Technology, Operations & Systems

Site institucional do **LYTOS**, uma página de laboratório fictício de pesquisa e desenvolvimento focado em **robótica, inteligência artificial e automação de alta performance**. O projeto está sendo desenvolvido como trabalho em equipe para a matéria de Front-End.

## Sobre o projeto

A plataforma apresenta a infraestrutura de um centro de P&D fictício, reunindo:

- Apresentação institucional do laboratório;
- Galeria de projetos, eventos e inovações desenvolvidos pelo LYTOS;
- Informações sobre produtos e serviços oferecidos;
- Página/seção de contato;
- Área de acesso a **conteúdos exclusivos**, com a interface de login/autenticação implementada no front-end (sem integração com backend/API real).

O design foi todo prototipado no Figma antes da implementação, servindo como guia visual.

> **Este é um projeto exclusivamente front-end.**
